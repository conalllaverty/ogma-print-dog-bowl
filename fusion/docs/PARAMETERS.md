# Parameter reference

Every value below appears in Fusion under **Modify > Change Parameters**. Type
a new number, press Enter, and the timeline rebuilds.

They all carry the `ogma` prefix so they sort together and cannot collide with
anything you add by hand. Lengths are millimetres; counts and percentages are
unitless.

Rows written as an expression rather than a number are *derived* — edit what
they reference, not them, or you break the link.

> Generated by `fusion/tests/gen_parameter_doc.py`. Do not edit by hand.

## Values that are NOT parameters

A few things are structural rather than dimensional, and changing them needs the command re-run rather than a parameter edit:

- **the letters themselves** — the name is text, and Fusion User Parameters are numeric. Re-run **Ogma Bowl** to change it.
- **honeycomb column count** — derived from `ogmaHexCellRadius` and then quantised to an even number, so small edits to the cell radius may not change the pattern at all.
- **the wave sine seam** — sampled into splines at build time. `ogmaWaveAmp` and `ogmaWaveCount` are recorded as parameters for reference, but the seam surface only picks them up on a re-run.
